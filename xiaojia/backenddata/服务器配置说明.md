# MQTT服务器配置说明

## 当前配置

**MQTT服务器地址**: `118.31.63.5`  
**端口**: `1883`

## 使用方法

### 方法1：使用测试脚本（推荐）

直接运行测试脚本，已经配置好服务器地址：

```bash
cd xiaojia/backenddata
python test_subscribe.py
```

脚本会自动：
1. 连接到 `118.31.63.5:1883`
2. 订阅全部传感器数据 (sensor/#)
3. 将数据按类别保存到 `data/` 文件夹的三个JSON文件

### 方法2：使用API服务

启动服务：
```bash
python main.py
```

然后通过API连接：
```bash
# 连接MQTT服务器
curl -X POST http://localhost:8002/mqtt/connect \
  -H "Content-Type: application/json" \
  -d '{
    "broker": "118.31.63.5",
    "port": 1883
  }'

# 订阅全部数据 (sensor/#)
curl -X POST http://localhost:8002/subscribe/start \
  -H "Content-Type: application/json" \
  -d '{
    "sensor_types": ["all"]
  }'

# 或订阅特定类型
curl -X POST http://localhost:8002/subscribe/start \
  -H "Content-Type: application/json" \
  -d '{
    "sensor_types": ["temperature", "humidity", "pressure"]
  }'
```

## 修改配置

如果需要修改服务器地址，编辑以下文件：

### test_subscribe.py
```python
MQTT_BROKER = "118.31.63.5"  # 修改这里
MQTT_PORT = 1883
```

### main.py
默认值在 `MQTTConfig` 类中，或通过API调用时指定。

## 数据存储位置

数据会自动保存到 `data/` 文件夹，按类别分成三个JSON文件：

```
xiaojia/backenddata/data/
  ├── temperature.json  (温度数据)
  ├── humidity.json    (湿度数据)
  └── pressure.json    (气压数据)
```

每个文件每行一个JSON对象，格式为：**时间、类别(topic)、值**

示例：
```json
{"timestamp": "2014-02-17T16:50:00", "topic": "sensor/temperature", "value": 7.0}
{"timestamp": "2014-02-17T17:00:00", "topic": "sensor/temperature", "value": 6.0}
```

## 常见问题

### 连接失败
1. 检查网络连接
2. 确认服务器地址和端口正确
3. 检查防火墙设置
4. 确认MQTT服务器正在运行

### 需要用户名密码
如果服务器需要认证，修改配置：
```python
MQTT_USERNAME = "your_username"
MQTT_PASSWORD = "your_password"
```

## 订阅类型说明

- `["all"]` - 订阅全部传感器数据 (sensor/#)，推荐使用
- `["temperature"]` - 只订阅温度数据
- `["humidity"]` - 只订阅湿度数据
- `["pressure"]` - 只订阅气压数据
- `["temperature", "humidity", "pressure"]` - 订阅多个类型
