# 小嘉智能环境监控系统 - 订阅端使用说明

## 快速开始 - 测试数据订阅

### 方法1：使用测试脚本（推荐）

1. **安装基础依赖**（只需要MQTT相关）：
```bash
pip install paho-mqtt
```

2. **运行测试脚本**：
```bash
cd xiaojia/backenddata
python test_subscribe.py
```

3. **修改配置**（如果需要）：
编辑 `test_subscribe.py`，修改以下配置：
```python
MQTT_BROKER = "118.31.63.5"  # MQTT服务器地址
MQTT_PORT = 1883
SENSOR_TYPES = ["all"]  # 订阅全部传感器数据 (sensor/#)
# 或选择特定类型: ["temperature", "humidity", "pressure"]
```

4. **查看数据**：
数据会自动保存到 `data/` 文件夹，按类别分成三个JSON文件：
```
data/
  ├── temperature.json  (温度数据)
  ├── humidity.json    (湿度数据)
  └── pressure.json    (气压数据)
```

### 方法2：使用完整API服务

1. **安装所有依赖**：
```bash
pip install -r requirements.txt
```

2. **启动服务**：
```bash
python main.py
```

服务将在 `http://0.0.0.0:8002` 启动

3. **使用API订阅数据**：
```bash
# 连接MQTT
curl -X POST http://localhost:8002/mqtt/connect \
  -H "Content-Type: application/json" \
  -d '{"broker": "localhost", "port": 1883}'

# 订阅全部数据 (sensor/#)
curl -X POST http://localhost:8002/subscribe/start \
  -H "Content-Type: application/json" \
  -d '{"sensor_types": ["all"]}'

# 或订阅特定类型
curl -X POST http://localhost:8002/subscribe/start \
  -H "Content-Type: application/json" \
  -d '{"sensor_types": ["temperature", "humidity", "pressure"]}'
```

## 常见问题

### 1. pandas无法解析

**问题**：如果只是测试订阅功能，不需要pandas。

**解决方案**：
- 订阅功能只需要：`paho-mqtt`
- 数据分析功能才需要：`pandas`, `numpy`, `scikit-learn`, `scipy`

**快速测试订阅**（不安装pandas）：
```bash
pip install paho-mqtt
python test_subscribe.py
```

**完整功能**（需要数据分析）：
```bash
pip install -r requirements.txt
```

### 2. 无法连接到MQTT服务器

**检查项**：
1. MQTT服务器是否运行
2. 地址和端口是否正确
3. 防火墙是否阻止连接
4. 是否需要用户名和密码

### 3. 数据没有保存到data文件夹

**检查项**：
1. 确保有写入权限
2. 检查控制台是否有错误信息
3. 确认订阅是否成功（查看控制台输出）

## 数据格式

每个JSON文件每行一个数据对象，格式为：**时间、类别(topic)、值**

**temperature.json**:
```json
{"timestamp": "2014-02-17T16:50:00", "topic": "sensor/temperature", "value": 7.0}
{"timestamp": "2014-02-17T17:00:00", "topic": "sensor/temperature", "value": 6.0}
```

**humidity.json**:
```json
{"timestamp": "2014-02-17T16:50:00", "topic": "sensor/humidity", "value": 53.0}
{"timestamp": "2014-02-17T17:00:00", "topic": "sensor/humidity", "value": 42.0}
```

**pressure.json**:
```json
{"timestamp": "2014-02-17T16:50:00", "topic": "sensor/pressure", "value": 1010.0}
{"timestamp": "2014-02-17T17:00:00", "topic": "sensor/pressure", "value": 1011.0}
```

## 订阅类型说明

- `["all"]` - 订阅全部传感器数据 (sensor/#)
- `["temperature"]` - 只订阅温度数据
- `["humidity"]` - 只订阅湿度数据
- `["pressure"]` - 只订阅气压数据
- `["temperature", "humidity", "pressure"]` - 订阅多个类型
