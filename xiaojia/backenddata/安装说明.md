# 安装说明 - 解决pip安装错误

## 问题：pip安装时出现 setuptools 错误

如果遇到类似以下错误：
```
AttributeError: module 'pkgutil' has no attribute 'ImpImporter'
```

这是因为Python 3.12+与旧版本的setuptools不兼容。

## 解决方案

### 方法1：升级pip和setuptools（推荐）

```bash
python -m pip install --upgrade pip setuptools wheel
```

然后重新安装依赖：
```bash
# 仅订阅功能（推荐先测试这个）
pip install paho-mqtt

# 或完整功能
pip install -r requirements.txt
```

### 方法2：使用conda安装（如果使用Anaconda）

```bash
# 仅订阅功能
conda install -c conda-forge paho-mqtt

# 完整功能
conda install -c conda-forge fastapi uvicorn paho-mqtt pandas numpy scikit-learn scipy matplotlib
```

### 方法3：单独安装paho-mqtt（最简单）

如果只需要测试订阅功能，只需要安装paho-mqtt：

```bash
pip install paho-mqtt
```

这个包通常不会有兼容性问题。

## 快速测试

安装paho-mqtt后，直接运行测试脚本：

```bash
cd xiaojia/backenddata
python test_subscribe.py
```

## 如果仍然有问题

1. **检查Python版本**：
   ```bash
   python --version
   ```

2. **使用虚拟环境**（推荐）：
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   pip install --upgrade pip setuptools wheel
   pip install paho-mqtt
   ```

3. **使用pip的--no-build-isolation选项**：
   ```bash
   pip install --no-build-isolation paho-mqtt
   ```
